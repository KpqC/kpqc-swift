# Changelog

## 0.2.1

- Synchronized HAETAE with the pinned upstream reference implementation.
- Standardized KEM terminology and pinned upstream source revisions.
- Validated all supported parameter sets against the shared KAT repository.

- Replaced AIM2 with AIM3 and updated AIMer signature sizes.
- AIMer keys and signatures from 0.1.x are not compatible with this release.

- Initial release.
